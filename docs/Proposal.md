# YogaFlow 3D
## 視覺化智慧：重新定義居家瑜珈

> 數據自主 • 即時引導 • 個性化成長

---

## 1. 打破反饋黑箱

**為什麼 90% 的居家練習者無法持續進步？因為他們看不見自己的錯誤。**

### 影片練習的侷限
傳統瑜珈影片只有單向輸出，練習者無法得知自己的脊椎是否過度彎曲，或關節角度是否安全。

### 昂貴的私教成本
高品質的私人教練每小時收費昂貴且需配合預約，難以滿足隨時隨地練習的需求。

### 核心痛點：自學者的視覺盲區

---

## 2. 視覺化關節引導

**「看見」看不見的角度**

系統自動計算教練影片中的「標準角度」與使用者「當前角度」的毫秒級差異。

- **紅區警示**：當關節偏離超過閾值
- **動態引導**：箭頭指示動作修正方向
- **實時疊加**：3D 骨架與影像合一

---

## 3. 個性化身體基線追蹤

| 功能 | 說明 |
|------|------|
| **活動度評估** | 記錄每個關節的極限 ROM (Range of Motion)，為每位使用者建立獨特的身體檔案 |
| **疲勞感知** | 分析動作穩定度，判斷肌肉疲勞程度，適時建議休息以預防受傷 |
| **平衡分析** | 透過重心追蹤與雙側角度對比，優化身體對稱性與核心穩定 |

---

## 4. 目標差距動態分析

> 「目前您的關節活動度已提升 25%，距離目標英雄三式尚有 12 度的傾斜優化空間。」

**進步路徑可視化：邁向大師級標準**

系統不僅顯示「不對」，更分析你與「目標」的距離，將練習變成有趣的升級過程。

---

## 5. 技術核心：Edge-AI 視覺引擎

利用 MediaPipe 實現高效能 3D 骨架抽取與 33 個關鍵點追蹤，確保側向、倒立等複雜姿勢依然穩定。

### 系統架構

```
CameraX (影像輸入)
    ↓
MediaPipe Pose (33 關鍵點 3D 骨架)
    ↓
Pose-aware State Machine (姿勢判斷)
    ↓
Flow Engine (時序控制)
    ↓
Gemma LLM on-device (語言層)
    ↓
TTS + 3D Avatar Coach (輸出)
```

## 6. 極致隱私：數據的主權在您

**100% 離線推理 (Local-Only) — 影像不離機，安心居家**

我們理解居家練習的私密性。YogaFlow 3D 的所有分析均在手機晶片內完成。

- 分析後即刻銷毀原始影像
- 完全不需要昂貴的雲端訂閱
- 在飛航模式下也能完美運行

```
04 成長回饋  →  檢視目標差距報告，解鎖下個難度
```
