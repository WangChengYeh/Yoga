# YogaFlow 3D
## 視覺化智慧：重新定義居家瑜珈

> 數據自主 • 即時引導 • 個性化成長

---

## 1. 打破反饋黑箱

**為什麼 90% 的居家練習者無法持續進步？因為他們看不見自己的錯誤。**

### 影片練習的侷限
傳統瑜珈影片只有單向輸出，練習者無法得知自己的脊椎是否過度彎曲，或關節角度是否安全。

### 昂貴的私教成本
高品質的私人教練每小時收費昂貴且需配合預約，難以滿足隨時隨地練習的需求。

### 核心痛點：自學者的視覺盲區
自學者最大的問題不是不努力，而是缺少即時、可視化、可量化的回饋。傳統影片只能示範「應該怎麼做」，卻無法指出「你現在差在哪裡」。

---

## 2. 視覺化關節引導

**「看見」看不見的角度**

YogaFlow 3D 透過手機鏡頭分析使用者姿勢，將身體動作轉換為可量化的關節角度與骨架狀態。系統可以比較標準姿勢角度與使用者當前角度，並用畫面與語音給出即時回饋。

- **紅區警示**：當關節偏離超過閾值
- **動態引導**：箭頭指示動作修正方向
- **實時疊加**：3D 骨架與影像合一

---

## 3. 個性化身體基線追蹤

| 功能 | 說明 |
|------|------|
| **活動度評估** | 記錄每個關節的極限 ROM (Range of Motion)，為每位使用者建立獨特的身體檔案 |
| **疲勞感知** | 分析動作穩定度、角度衰退與身體抖動，判斷肌肉疲勞程度，適時建議休息以預防受傷 |
| **平衡分析** | 透過重心追蹤與雙側角度對比，優化身體對稱性與核心穩定 |
| **節奏管理** | 依據年齡、身體狀況、姿勢角度、抖動幅度與肌肉負荷，主動調整每個姿勢的練習時間、強度與休息間隔 |

### 主動休息與強度控制

YogaFlow 3D 不只是提醒使用者「姿勢對不對」，也會管理「該練多久、該休多久」。每個姿勢對不同肌群的刺激強度不同，系統會根據使用者年齡、活動度、角度偏差、穩定度與抖動狀況，動態調整訓練節奏。

當系統偵測到角度開始失控、身體抖動增加、左右側穩定度下降或動作補償變明顯時，AI 教練會主動降低強度、縮短維持時間、延長休息，或建議切換到替代姿勢，避免過度運動與累積性傷害。

## 5. 技術核心：Edge-AI 視覺引擎

利用 MediaPipe 實現高效能 3D 骨架抽取與 33 個關鍵點追蹤，確保側向、倒立等複雜姿勢依然穩定。

### 系統架構

```
CameraX (影像輸入)
    ↓
MediaPipe Pose (33 關鍵點 3D 骨架)
    ↓
Pose-aware State Machine (姿勢判斷)
    ↓
Flow Engine (時序控制)
    ↓
Gemma LLM on-device (語言層)
    ↓
TTS + 3D Avatar Coach (輸出)
```

### Flow DSL 驅動課程

YogaFlow 3D 的課程不是由 LLM 隨機生成，而是由結構化 Flow JSON 定義：

```text
setup → movement → hold → correction → transition
```

每一步都可以指定教練提示語、偵測條件、關節角度門檻、穩定時間與修正語句。系統根據偵測結果決定目前步驟是否完成、是否需要修正、是否可以進入下一步。LLM 只負責語氣潤飾，不負責改變課程順序。

## 6. 極致隱私：數據的主權在您

**100% 離線推理 (Local-Only) — 影像不離機，安心居家**

我們理解居家練習的私密性。YogaFlow 3D 的所有分析均在手機晶片內完成。

- 分析後即刻銷毀原始影像
- 完全不需要昂貴的雲端訂閱
- 在飛航模式下也能完美運行

居家練習發生在高度私密的空間，AI 教練必須尊重資料主權。YogaFlow 3D 的產品原則是不販售使用者影像資料，不把私人身體資料變成雲端黑箱。

## 7. 極簡練習流程

YogaFlow 3D 提供兩種練習入口：**標準流程**與**客製化流程**。標準流程主打立即開始，客製化流程主打從使用者信任的影片中抽取動作，建立個人化練習。

### 標準流程：內建初級／中級／高級瑜珈

```
01 選擇難度  →  初級、中級、高級內建瑜珈流程
02 開始練習  →  AI 教練依照內建動作順序帶領練習
03 即時修正  →  姿勢角度、穩定度、抖動與呼吸節奏提示
04 主動休息  →  依肌肉負荷與身體狀況調整 hold 時間與休息間隔
05 成長回饋  →  檢視活動度、肌肉負荷、恢復建議與下一階段難度
```

### 客製化流程：影片本機抽取與個人化練習

```
01 匯入來源  →  YouTube、物理治療師影片或手機收藏影片
02 本機抽取  →  手機端分析影片動作，抽取姿勢順序、關節角度與節奏
03 建立流程  →  將抽取出的動作加入個人練習清單
04 互動練習  →  依客製化流程進行即時視覺反饋、語音引導與休息管理
05 持續調整  →  依使用者年齡、身體狀況、角度與抖動動態調整強度
```

### 客製化隱私原則

客製化流程中的影片分析全部在手機本機完成。無論來源是 YouTube、物理治療師影片或手機收藏影片，影片內容、使用者練習影像與抽取後的姿勢資料都不需要上傳雲端，確保「影片不離手機、身體資料不離手機」。

## 8. 居家練習展示場景

**場景：低光源臥室中的單人居家瑜珈練習**

在家中臥室環境，單一使用者穿著貼身運動服裝，可在床上或床邊進行瑜珈練習。簡單、低風險、睡前放鬆類姿勢，例如仰躺伸展、簡易扭轉、腿部放鬆與呼吸練習，可直接在床上完成；需要較大活動範圍或平衡控制的姿勢，則建議移到床邊或瑜珈墊上進行。房間採用紅色氛圍燈與紅外線感測輔助，在低光源條件下依然能維持姿態辨識穩定度。

紅光與近紅外線可作為晚間練習的輔助環境設計。相較於高亮度白光，低光源與紅色氛圍燈更適合睡前放鬆場景；紅光與近紅外線也常被用於粒線體與恢復相關的健康輔助設備。YogaFlow 3D 支援這類低光源、紅光與紅外線輔助環境，讓使用者可在不破壞睡前氛圍的情況下進行緩和伸展與放鬆練習。

床邊或床頭放置手機與網紅常用手機架，手機鏡頭對準練習者全身或主要活動區域。YogaFlow 3D 透過前鏡頭或外接視角捕捉單一使用者的身體關鍵點，在畫面上疊加 3D 骨架、關節角度與修正箭頭，並由 AI 教練即時指導瑜珈姿勢。

### 展示重點

- **床上簡單姿勢**：支援仰躺伸展、簡易扭轉、腿部放鬆、呼吸練習等低風險睡前動作
- **低光源可用性**：紅色燈光與紅外線輔助下仍可進行姿勢追蹤
- **睡眠友善場景**：支援低光源、紅光與睡前緩和伸展流程，降低高亮度光源對放鬆氛圍的干擾
- **紅光 / 近紅外線輔助**：可搭配市售紅光、近紅外線或紅外線輔具，支援恢復與放鬆導向的練習情境
- **真實居家場景**：床上、床邊、手機、手機架即可完成互動練習
- **單人姿態追蹤**：系統鎖定主要練習者，避免背景人物或環境物件干擾判斷
- **AI 即時指導**：語音提示調整手臂、髖部、膝蓋與脊椎角度
- **隱私優先**：臥室影像只在本機分析，不上傳雲端

## 9. B2B 企業合作：養生村與物理治療師處方流程

YogaFlow 3D 可延伸到養生村、銀髮住宅、復健中心與物理治療診所，作為長者日常活動、姿勢訓練與復健追蹤的數位平台。

### 長者節奏微調

針對長者使用者，系統會依年齡、活動度、平衡能力、抖動程度與關節角度，微調每個姿勢的速度、強度、維持時間與休息間隔。AI 教練不追求快速完成動作，而是優先確保安全、穩定與可持續練習。

### 物理治療師處方流程

物理治療師可將「處方簽」轉換成一組專屬練習流程。每個流程包含指定姿勢、順序、組數、維持秒數、休息時間、禁止動作與特別注意事項。

例如：

- 縮小腹，啟動核心，避免腰椎代償
- 頸部微縮，保持下巴內收，避免頸椎過度前伸
- 膝蓋不要超過腳尖，降低膝關節壓力
- 動作過程保持慢速，不追求最大角度

### 逐筆收費模式

不同治療師可為不同住民或病患開立不同的客製化流程。每一張處方流程都可作為一次付費項目，依「治療師 × 使用者 × 流程」逐筆收費。養生村或診所可採用機構授權、住民帳號管理、治療師後台與處方流程管理。

## 10. 盈利模式

**免費完整功能 + 個性化加值服務 + B2B 處方流程**

YogaFlow 3D 的核心 App 採免費模式，讓使用者不付費也能使用完整的姿勢偵測、即時語音指導、3D 骨架疊加與基本練習流程。商業模式不以限制核心功能為主，而是透過個人化、內容擴充、企業合作與生態合作創造收入。

### 收入來源

| 模式 | 說明 |
|------|------|
| **客製化瑜珈流程** | 使用者可付費建立個人化訓練流程，例如 YouTube、物理治療師影片或手機收藏影片的本機動作抽取與個人練習清單 |
| **B2B 處方流程** | 養生村、復健中心或治療師可替長者與病患建立專屬流程，依治療師、使用者與流程逐筆收費 |
| **輔具推薦合作** | 根據使用者姿勢需求與場景推薦瑜珈墊、瑜珈磚、伸展帶、手機架、紅光燈、近紅外線輔具、紅外線補光設備等，並向合作廠商收取推薦、導購或曝光費用 |
| **3D 教練 Skin** | 基本 AI 教練免費；不同風格的 3D 健身教練外觀、聲線、服裝與互動風格可作為付費 skin 或主題包 |
| **品牌聯名內容** | 與健身教練、瑜珈老師、網紅或運動品牌合作推出聯名流程與專屬教練角色 |

### 原則

- **核心功能免費完整**：姿勢偵測、角度提示、基礎流程與隱私保護不設付費牆
- **付費買的是個性化與體驗**：不是為了移除限制，而是取得更貼近個人目標的流程與教練形象
- **醫療與復健場景由專業人員定義流程**：系統負責執行、提示與追蹤，不取代物理治療師診斷
- **紅光與紅外線作為輔助情境**：App 支援相關低光源與輔具情境，但不宣稱取代醫療治療
- **推薦透明化**：輔具推薦需標示合作或贊助關係，避免破壞使用者信任
- **不販售使用者影像資料**：商業化不建立在上傳、販售或分析私人影像資料之上

## 13. 現階段產品落地狀態與關鍵產品原則

目前 repo 已具備：

- Android app 架構
- CameraX camera pipeline
- MediaPipe pose integration
- Flow JSON DSL v2
- 20 個 packaged Flow DSL 課程
- strict detection routing
- pose-specific detection mappers
- runtime tuning override
- numeric fail reason
- auto tuning suggestion
- LLM-assisted coach cue
- TTS voice output
- Godot 3D Avatar coach overlay
- session history 與統計基礎功能
- JVM integration tests for packaged flow/runtime contracts

目前仍在進行或規劃：

- flow library 擴充到 30+ flows
- ROM baseline tracking
- bilateral balance analysis
- Apple Fitness+ style home screen polish
- teacher-video-to-flow authoring pipeline
- Android UI / screenshot / Godot bridge tests
- CI validation for JDK 17 build and JVM tests

### 關鍵產品原則

- **Flow JSON 是課程真相來源**：LLM 不應自由編排課程，不應新增影片中沒有的動作，也不應重排教學順序。
- **動作必須可量化**：每個姿勢都應能被角度、穩定時間與偵測條件描述。
- **回饋必須可解釋**：系統不只說「錯了」，也應說明哪個角度錯、差多少、應該往哪裡修。
- **隱私是產品核心**：使用者的影像與身體資料不應成為雲端黑箱。

## 14. Agentic AI 開發流程

本專案採用 PM、RD、AE 三角色的 Agentic AI 協作模式，讓產品規格、核心技術與應用落地可以並行推進。

| 角色 | 定位 | 主要職責 | 產出 |
|------|------|----------|------|
| **PM（Product Manager）** | 規格與需求負責人 | 定義使用者場景、產品需求、商業模式、功能優先級與驗收標準 | PRD、User Story、Issue、驗收條件 |
| **RD（Research & Development）** | 核心技術實作者 | 實作姿勢偵測、3D 骨架、角度計算、Flow Engine、on-device AI 與效能優化 | 核心模組、演算法、SDK、測試報告 |
| **AE（Application Engineer）** | 應用整合與體驗落地 | 將 RD 核心能力整合到 App，完成 UI/UX、教練互動、場景流程、輔具推薦與商業化功能 | App 功能、Demo、整合文件、使用流程 |

### 協作節奏

```
PM 定規格與驗收標準
    ↓
RD 開發核心能力與技術模組
    ↓
AE 整合成可用 App 與展示場景
    ↓
PM 驗收體驗、重新排序需求
```

### Agentic AI 分工

- **PM Agent**：整理需求、拆解 GitHub Issues、維護 roadmap、確認每個功能的使用者價值與驗收標準
- **RD Agent**：修改核心程式碼、建立測試、處理 MediaPipe / CameraX / 3D 骨架 / LLM on-device 等技術問題
- **AE Agent**：負責 App 端串接、Demo 場景、提示詞文案、教練互動流程與商業化功能整合

指令頻道：GitHub Issues 作為任務來源，Pull Request 作為交付與審查節點。
