# YogaFlow 3D Project Plan

## Executive Summary
YogaFlow 3D 是一款完全在手機本地端運行的 3D 姿勢分析與語音指導系統。

## Value Proposition
- 極致隱私（On-device AI）
- 專業 3D 生物力學建模
- Agentic AI 加速研發
- 離線 LLM 指導

## Core Technologies
- MediaPipe Pose Landmarker
- Python 3.13 Android
- NumPy / SciPy
- MediaPipe LLM (Gemma)

## Product Features
- 3D Skeleton Preview
- Voice Coaching
- Privacy-first data pipeline
- Local progress report
